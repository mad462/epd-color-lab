# 48 色屏实测校准说明

## 怎么测

1. 串口里敲 `c` 进入校准模式（默认 ColorQual 3 相，共 52 个色）
2. 敲数字 + 回车跳到某个编号；`n`/`p` 下一个/上一个
3. 每个颜色全屏刷一次，约 15 秒
4. **仪器测屏幕中心**（满屏纯色，避开边框）
5. 敲 `f` 可切到 ColorFast 2 相（共 57 个色）
6. `x` 退出校准

## 串口会打出什么

```
CAL,1,3,1F192B,31,25,43
```

格式是 `CAL,编号,原始索引,标称HEX,标称R,标称G,标称B`。
把实测值补在后面发回来即可，例如：

```
CAL,1,3,1F192B,31,25,43  实测 #221C30 (34,28,48)
```

## 要填的表

- `校准表_qual.csv` —— ColorQual 3 相，52 个
- `校准表_fast.csv` —— ColorFast 2 相，57 个

## 实测值拿来干嘛

把标称色板换成**实测色板**后重新量化：

- 量化时按「实际会渲染成什么颜色」来选，而不是按厂商标称值
- 能纠正色偏，也能让抖动算出的中间色更接近真实观感
- 实测色板只影响 host 侧的 .act，**不用重新烧固件**
