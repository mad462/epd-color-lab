# 配网

**固件里不含 WiFi 密码。** 密码只存在设备自己的 NVS 里，代码里一个字符都没有 ——
把密码编译进源码，推到公开仓库就等于公开发布。

配一次就够：NVS 掉电不丢，重烧固件也不清（除非擦 flash）。

---

## 方法一：配网助手（推荐）

```bash
python host/wifi_setup.py
```

它会问你要 SSID 和密码。密码用 `getpass` 读 —— **不回显，也不进命令历史**。
写完当场生效，并打印设备 IP。

```bash
python host/wifi_setup.py -s MyWiFi       # 只问密码
python host/wifi_setup.py --clear         # 清掉设备里保存的 WiFi
python host/wifi_setup.py --port COM7 -v  # 换串口 + 看设备完整输出
```

### 网页里配

传图台（`host/server.py` 起来之后）右上角有「配网」按钮，弹窗里填 SSID / 密码。
和上面的脚本走同一条路（都调助手的 `POST /provision`），配完自动读回一次 IP。

用过的 WiFi 会变成标签列在输入框下面，点一下直接填。
**密码存在浏览器 localStorage 里** —— 本机自用方便，公用电脑上别用。

## 方法二：串口里敲 `W`

任意串口工具（115200）里敲**大写** `W`：

```
=== WiFi 配网 ===
  当前    : （还没配过）
  说明    : 密码只存进设备 NVS，固件里没有；不回显、不打印
  取消    : 按 ESC
  清除    : SSID 处输入一个 S 回车

WiFi 名称（SSID）: MyWiFi
密码（输入不回显，输完回车）: ********

正在保存到 NVS 并连接 MyWiFi …
等待拿 IP.......
✓ 已连上，IP = 192.168.3.10
  网页传图地址: http://192.168.3.10/
```

| 操作 | 说明 |
|---|---|
| 密码 | 用 `*` 回显，**不打明文**，免得留在日志或录屏里 |
| `ESC` | 取消 |
| 退格 | 可删 |
| SSID 处输 `S` | 清除已保存的凭据 |

> 开机自动进**校准模式**，`W` 会先自动退出校准再执行。

## 查 IP

串口里敲 `e`：

```
--- 设备信息 ---
  WiFi      : 已连接
  设备 IP   : 192.168.3.10
  网页传图  : http://192.168.3.10/
  图片目录  : /sdcard/e6
```

网页里点「配网」→「读取设备IP地址」也能读（走助手的 `GET /device`）。

**为什么不自动发现设备**：网页没法扫描局域网。所以 IP 得手动拿一次，
之后存在浏览器本地。

---

## 注意

**打开串口会让板子复位一次**（CH343 的 DTR/RTS 会跳一下），重启后 2~3 秒重新连上
WiFi。所以读 IP、配网这些操作都要等它起来。

串口是**独占资源** —— 同一时刻只能一个程序用。助手的每次操作都是**用完即关**，
不会一直占着；但如果你同时开着串口监视器，就会互斥。
