# 三块面板的对比：为什么 3.7″ 能 48 色，7.3″ 不行

> 起因：确认 7.09″（EPD0709A02）和 7.3″（GDEP073E01）能不能也刷 48 色。
>
> 结论一句话：**48 色不是"算法"做出来的，是"面板架构 + 波形"支持的。
> 3.7″ 那块屏两个条件都满足；7.3″ 卡在波形上；7.09″ 资料不足。**

---

## 一、三块屏

| | **3.7″（在用）** | **7.3″** | **7.09″** |
|---|---|---|---|
| 型号 | 兴泰 EPD037A02 / JD7601 级 | GDEP073E01 | Osptek EPD0709A02 |
| 分辨率 | 720 × 480 | 800 × 480 | 1200 × 1600 |
| 主控 IC | JD7601 级 | **NT61522** | **TBD（规格书没写）** |
| 帧存 | **2 个平面** | **1 个 SRAM**（1600×800×**3 bit**） | 未知 |
| 原色 | 6（黑白红黄蓝绿） | 6（黑白红黄蓝绿）+ 橙 | 6（黑白红黄蓝绿） |

| **48 色** | ✅ **跑通了** | ❌ 卡在波形 | ❓ 资料不足 |

## 二、48 色的真实机理

**核心：一屏同时能显示几种颜色，由「帧存位宽 × 刷新遍数」决定，不是软件能变的。**

### 3.7″ 是怎么做到的

```
8bpp 索引 = 高 3 位 × 8 + 低 3 位

高 3 位  ->  写到「平面 0」   ->  相位 1 显影
                                 相位 2（复用 RAM，不重传）
低 3 位  ->  写到「平面 1」   ->  相位 3 显影
```

**这是两个平面 × 三个相位。** 8 × 8 = 64 种组合，去掉没有波形的空条目，剩 **48 种可用的**。

### 7.3″ 为什么不行

实测（见 `C:\FUCKEDA\e6-730\docs\实测记录.md`）：

1. **NT61522 只有一个 3-bit 帧存** → **一次刷新最多 8 个状态**
2. 实测 8 个状态里 **`0x7` 和白色逐像素完全一致**（1 像素棋盘格测不出任何花纹）
   → LUT 把这个状态复用成白色了，**实际只有 7 色**
3. DKE（厂商）说：**超过 8 色要用多次刷新**，二次刷新能到 8×8
4. **但实测否定**：现在这版波形是**饱和型** —— 无论源状态是什么，目标都被推到同一个终点。
   多遍刷新**没用**。

> **饱和型波形**：`LUT[任意源][目标]` 的可视结果都一样。
> 而多遍刷新要求 `LUT[源][目标]` 依赖源 —— 第一遍把像素推到中间态，第二遍从那里接着推。

**所以 7.3″ 的颜色上限就是 7 色，软件层面没有别的办法。**

---

## 三、关键洞察：3.7″ 的「三相」就是「多遍刷新」

DKE 描述的多遍刷新：*「第一遍把像素推到某个中间态，第二遍从那里再推，就能到达单遍到不了的地方。」*

**这和 3.7″ 的三相 ColorQual 波形是同一件事** —— 只不过：

| | 7.3″ 需要 | 3.7″ 实际做的 |
|---|---|---|
| 怎么实现"多遍" | 刷新**两次**（每次 19.6 秒） | 一次刷新里跑**三个相位** |
| 中间态存哪 | 面板上（颜料位置是连续的） | 同上 |
| 第二遍的源从哪来 | 第一遍的目标 | 相位 2 复用 RAM，不重传 |
| 总耗时 | ~40 秒 | ~15 秒 |

**3.7″ 那块屏的波形天生就是非饱和型的**（FrameFilm 逆向出来的），所以三相能接续。

**7.3″ 想要 48 色，唯一的路是拿到一版非饱和型波形。**

## 四、7.09″ 的情况

规格书（`EPD0709A02.pdf`）里**没有驱动 IC 型号**，只有：

> **EPD driving Waveform: Provided and downloaded by BOE**

**两件事必须先问到，否则没法判断：**

1. **驱动 IC 型号 + datasheet** —— 决定有没有第二个平面
   - 有双平面（像 JD7601）→ **直接能做**，改改分辨率就行
   - 只有单平面 → 和 7.3″ 一样，需要非饱和波形
2. **波形文件** —— 或者问能不能自己写 LUT

**另外数据量是 5.5×**：

| | 3.7″ | 7.09″ |
|---|---|---|
| 像素 | 0.35 Mpx | **1.92 Mpx** |
| 8bpp 索引缓冲 | 346 KB | 1.92 MB |
| 单平面 1bpp | 43 KB | 240 KB |

ESP32-S3 的 8 MB PSRAM **放得下** ✓ 但规格书面板六色刷新就要 **27 秒**，
48 色要 3~4 个相位 → **估计 1~2 分钟一次**。

## 五、顺带：规格书验证了镜面项校正

EPD0709A02 规格书的测量条件是 **45°/0**（不是 D/8 SCI）：

> Measurements are made with the illumination under an angle of **45 degrees**,
> the detector is **perpendicular**. 仪器：Eye-One Pro 3 plus

| | 白色 L\* | 对比度 |
|---|---|---|
| **BOE 规格书**（45/0） | **66** | **15 (min) / 22 (typ)** |
| 我们的 LS173（D/8 **SCI**） | ~72 | — |
| 我们推的 b=5.1% 校正后 | | **19.7:1** |

**对比度 15~22 和我们用物理边界反推的完全一致** —— 说明 b ≈ 5% 的镜面项
估计是对的，D/8 SCI 仪器确实把镜面反射算进去了（白偏亮约 6 个 L\*）。

详见 [颜色方法论.md](颜色方法论.md) 的「测量偏差」一节。
